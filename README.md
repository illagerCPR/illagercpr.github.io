基于 GitHub Pages 的个人主页（自定义域名）：<https://www.illageraris.dpdns.org/>

采用作品展厅布局：顶部导航、个人介绍、带轻量示意图的重点项目与项目目录。单页纯静态站，零依赖、无构建，手机与桌面自适应。默认跟随系统的明暗偏好，也可以手动切换；项目可按类型或语言筛选，有许可协议的项目会标注协议类型。
