watermark

纯前端图片水印工具：支持多行文本平铺水印、DFT 频域盲水印（无需原图即可提取）与批量处理。基于 Canvas API，零依赖、零外部库。

JavaScript图片处理Canvas

keyshow

桌面端键盘、鼠标与手柄操作实时监控工具。支持键盘按键与组合键、鼠标滚动、手柄（Xbox / PS / NS）实时显示，窗口可贴边吸附、自定义设置。

RustVue 3Tauri 2Win32

hanoi

汉诺塔（Hanoi Tower）游戏，提供 GUI 与 CLI 双模式。支持 3~10 盘自适应、点击/拖拽移动、自动演示、计分系统与求解动画，基于 Python 标准库与 tkinter，零依赖。

PythontkinterGUI + CLI
